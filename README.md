# AG City — Aashutosh Gupta's portfolio

A 3D drivable portfolio. Drive through a food city to see design, marketing and software work, or switch to the traditional view.

Single self-contained `index.html` (three.js loads from cdnjs). No build step: open it or deploy the folder as a static site.

Controls: W A S D to drive, Shift for boost, Space to drift, E to open a stop.
